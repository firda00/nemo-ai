# Видео-демо Nemo AI для инвесторов

## Формат

- Длительность: 4–5 минут.
- Запись: экран 1440×900, масштаб браузера 100%, русский интерфейс.
- До записи: создать тестовую компанию «Nemo Demo School», подготовить FAQ с реальными демонстрационными ценами и убедиться, что тестовый чат, Agent Trace и нужные подключения отвечают.
- Не показывать секретные ключи, консоль браузера, Supabase, SSH или неподтверждённые интеграции.

## Готовый запрос для демонстрации

Вставить в «Автономные команды»:

> Создай AI-отдел продаж и поддержки для онлайн-школы. Нужны: руководитель команды, квалификатор лидов, специалист по базе знаний, follow-up менеджер, CRM-оператор и контролёр качества. Команда должна отвечать только по загруженной базе знаний, уточнять имя, телефон, интересующий курс и желаемую дату старта, готовить запись для CRM, передавать сложные или спорные вопросы человеку и показывать Agent Trace. Не придумывай цены, расписание, скидки и обещания. Для каждого результата укажи ответственного, проверяемый результат и следующий шаг.

Запрос для тестового клиента:

> Здравствуйте! Я выбираю курс frontend для команды из пяти сотрудников. Какие есть варианты, когда можно начать и что вам нужно от меня для расчёта предложения?

## Сценарий по времени

### 0:00–0:25 — проблема и позиционирование

Экран: главная Nemo AI, затем рабочая панель.

Текст:

> Компании уже используют отдельные AI-чаты, но бизнес-процесс всё равно остаётся ручным. Nemo AI собирает не одного бота, а управляемую команду AI-сотрудников: с ролями, общей памятью, инструментами, контролем качества и журналом действий.

### 0:25–1:15 — создание команды одним запросом

Экран: «Автономные команды». Вставить готовый запрос и запустить создание.

Текст:

> Я описываю бизнес-цель обычным языком. Nemo проектирует состав команды, разделяет ответственность и создаёт последовательный рабочий процесс. Здесь важно, что каждый специалист отвечает за конкретный результат, а спорные решения передаются человеку.

Показать созданные роли и их задачи. Не ускорять момент появления результата сильнее чем в 2 раза.

### 1:15–2:05 — знания и собственный skill

Экран: открыть агента → «База знаний», загрузить демонстрационный PDF/CSV; затем «Основные» → блок skills.

Текст:

> Агент получает проверенные данные компании из документов и таблиц. Готовые skills включаются переключателем. Собственный метод можно загрузить файлом: Nemo преобразует документ, конфигурацию или исходный текст в ограниченную инструкцию. Файл не исполняется как программа. После сохранения skill проверяется в тестовом чате.

Для записи использовать небольшой файл `sales-qualification.md` без персональных данных.

### 2:05–2:45 — плагины и инструменты

Экран: «Интеграции и инструменты» → «Мои инструменты».

Текст:

> Внешние действия подключаются как HTTP-инструмент или MCP-плагин. MCP-манифест заполняет форму, но не активируется автоматически: секрет вводится отдельно, затем Nemo запрашивает реальный список tools у сервера. Только после успешной проверки подключение можно сохранить.

Не показывать GitHub как подключённый, пока production executor и отдельный E2E smoke не подтверждены.

### 2:45–3:45 — живой клиентский запрос

Экран: тестовый чат созданного агента. Вставить запрос клиента.

Текст:

> Теперь отправим реальный запрос покупателя. Команда определяет намерение, проверяет базу знаний, собирает недостающие поля и готовит следующий шаг. Если в документах нет цены или даты, агент должен прямо сказать, что данные нужно подтвердить, а не придумывать ответ.

Показать ответ, собранные поля и Agent Trace. Открыть 2–3 шага trace и показать, какой агент что сделал.

### 3:45–4:25 — контроль и ценность

Экран: качество, задачи или аналитика — только раздел с реальными данными текущего прогона.

Текст:

> Руководитель видит не только итоговый ответ, но и маршрут работы: кто принял решение, какие данные использованы, где потребовался человек и какой следующий шаг создан. Это делает автоматизацию управляемой и позволяет измерять время, стоимость и качество на реальных запусках.

### 4:25–4:50 — завершение

Экран: тарифы.

Текст:

> Nemo AI превращает повторяемый процесс компании в контролируемую AI-команду. Клиент начинает с одного отдела, подключает свои знания и инструменты, проверяет результат и затем масштабирует подход на другие процессы.

## Тестовый skill-файл

Содержимое `sales-qualification.md`:

```md
# Квалификация B2B-лида

1. Определи задачу клиента и ожидаемый результат.
2. Уточни размер команды, срок запуска и критерий выбора.
3. Не называй цену или дату, если их нет в базе знаний.
4. Подготовь краткое резюме: потребность, команда, срок, риск, следующий шаг.
5. Перед коммерческим обещанием запроси подтверждение ответственного сотрудника.
```

## Формат MCP-манифеста

```json
{
  "kind": "mcp",
  "name": "demo_crm_tools",
  "description": "Поиск и подготовка записей CRM",
  "mcp_url": "https://mcp.example.com/mcp",
  "header_name": "Authorization"
}
```

Секреты в manifest-файл не добавлять. Максимальный размер манифеста — 64 КБ; адрес MCP должен использовать HTTPS; перед сохранением обязателен тест сервера.
