# NEMO — последовательное улучшение чата

Объём, подтверждённый владельцем 14 сентября 2026: понимание запросов, состояния действий, удобство ввода и входа, надёжность, затем честный лендинг. Ветка `codex/trial-booking-local`. Новые профессии, production, коммиты, сообщения клиентам и платные вызовы не входят в этап. Старый платный пакет закрыт и не возобновляется.

## Поведение

- Информационный вопрос о возможностях отвечает без вызова модели, не заменяет цель настройки и не становится заявкой на запись.
- Создание команды требует явного запроса на создание именно команды/агента. Вопрос об инструкции и текстовая отмена не создают конфигурацию. Уже указанные цель, источники и формат не спрашиваются повторно. Это ограниченный разбор явных полей, не доказательство полного семантического понимания моделью.
- Обычный чат удерживает последние 40 текстовых сообщений в текущей вкладке. `sessionStorage` привязан к origin, организации из JWT-проверенного профиля и пользователю. Файлы и исполняемые карточки не сериализуются. Frontier continuation — зашифрованные сервером данные диалога, не ключ API; её прежние серверные привязки и срок действия сохраняются.
- При восстановлении не отправляются запросы к модели и не исполняются действия. Документные задания возвращаются своим прежним путём чтения статуса. Запись на занятие использует прежнее серверное состояние.
- Перед отправкой снова проверяется организация. `contextAccountId` fast-chat — условие совпадения с уже проверенным серверным профилем, не источник полномочий. Несовпадение отклоняется до вызова модели.
- Вставка изображения показывает локальное превью; смешанная вставка сохраняет текст. Перезагрузка не сохраняет файл: его нужно приложить заново.
- Состояния записи локализованы. Подтверждение по-прежнему появляется только из отдельного чтения сохранённой записи; исполнитель, SQL и согласование не заменены.
- Лендинг использует существующую визуальную систему и знак. Иллюстрация пробной записи отделена от клиентских операций; интеграции требуют настройки.

## Воспроизведение

```powershell
npm run test:chat-experience
node agent-hub/trial-booking-ui-smoke.mjs
node agent-hub/trial-booking-local/setup.mjs prepare
node agent-hub/trial-booking-local/setup.mjs start
node agent-hub/trial-booking-local/setup.mjs reset
node agent-hub/trial-booking-local/integration.mjs
node agent-hub/trial-booking-local/app.mjs
# В другом терминале:
node agent-hub/trial-booking-local/browser-acceptance.mjs
npm run quality
```

Reset разрешён только для disposable-проекта `nemo-trial-booking-local`; нельзя использовать `--linked`. Перед повтором сохранять прежние результаты. Полный quality включает новые проверки через `test:chat-experience`. Для отдельных новых снимков лендинга задать `NEMO_LANDING_EVIDENCE_DIR` на каталог текущего этапа.

## Границы доказательств

`test:chat-experience` явно подменяет Auth/SDK/провайдера в браузерном и endpoint-пробниках. Он доказывает клиентское поведение и ветви серверного обработчика, не настоящий LLM E2E. Настоящая локальная база проверяется отдельными 21 интеграционным тестом и браузерным проходом. Внешний Google OAuth и физическая вставка на macOS требуют отдельного фактического прогона. Платные ответы модели в этом этапе не проверяются.

Актуальные результаты, хеши исходников, неуспешные попытки и пределы находятся отдельно в `agent-hub/artifacts/chat-improvements-20260914/`. Исторические отчёты trial-booking acceptance и закрытого платного пакета не являются отчётами текущего изменения.
