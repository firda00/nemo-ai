# Сценарий демонстрации Nemo AI для инвесторов

## Цель видео

За 4–5 минут показать полный цикл: создать AI-агента, добавить ему готовый навык, загрузить собственный skill-файл, подключить внешний инструмент и проверить результат в тестовом чате.

Важно: в демо показываются только реально доступные действия. GitHub и другие интеграции, для которых ещё нет production executor, должны оставаться в статусе «скоро».

## Подготовка до записи

1. Открыть production: https://nemo-ai-swart.vercel.app/
2. Войти в аккаунт или открыть заранее подготовленный demo-аккаунт.
3. Подготовить один небольшой PDF/CSV/DOCX с вымышленными данными компании. Не использовать реальные персональные данные и секреты.
4. Подготовить HTTPS MCP manifest без токена, например:

```json
{
  "kind": "mcp",
  "name": "demo_crm_tools",
  "description": "Тестовые CRM-инструменты для демонстрации",
  "mcp_url": "https://demo.example.com/mcp",
  "header_name": "Authorization"
}
```

Manifest можно загрузить в разделе «Инструменты», но сохранить plugin получится только после успешной проверки MCP-сервера.

## Текст ведущего и действия на экране

### 0:00–0:30 — Контекст

«Nemo AI превращает повторяемый бизнес-процесс в управляемого AI-агента. У агента есть роль, правила, знания, навыки и инструменты. Сегодня я покажу это на одном сценарии — подготовке краткого отчёта для руководителя».

Открыть «Агенты» и выбрать заранее созданного агента или нажать «Создать агента».

### 0:30–1:15 — Создание агента

Назвать агента `Investor Brief Analyst`.

В поле роли вставить: «Аналитик для подготовки управленческих выводов из документов и таблиц».

В задачах указать: «Находи ключевые показатели, изменения, риски и следующие действия. Отделяй факты от предположений и указывай источник».

Включить встроенные навыки:

- анализ данных;
- проверка доказательств в документах;
- отчёт для руководителя.

«Навыки выбираются отдельно от роли. Поэтому один и тот же тип агента можно адаптировать под финансы, продажи, поддержку или операционные задачи».

### 1:15–2:00 — Загрузка собственного skill-файла

В блоке «Свой skill из файла» нажать «Загрузить skill» и выбрать PDF, DOCX, XLSX, CSV, JSON, YAML, Markdown или другой текстовый файл.

«Nemo принимает документ как инструкцию: извлекает текст, ограничивает размер и объём prompt. Файл не запускается как программа. Архивы, исполняемые файлы и медиа не исполняются».

После импорта показать имя файла, сохранить агента и открыть тестовый чат.

### 2:00–3:00 — Live-тест агента

Вставить prompt из следующего раздела. Показать ответ, где есть:

- таблица ключевых метрик;
- раздел «Факты»;
- раздел «Гипотезы»;
- три риска;
- следующие действия с владельцем и сроком;
- ссылки или названия использованных источников.

«Результат можно проверить в тестовом чате до подключения канала или запуска рабочего процесса».

### 3:00–3:45 — Подключение инструмента или plugin

Открыть «Инструменты» → «Мои инструменты».

Показать два пути:

1. HTTP-инструмент: название, HTTPS endpoint, метод и параметры.
2. MCP plugin: загрузить manifest, указать секрет только в защищённом поле, нажать «Проверить MCP».

«Сохранение MCP plugin блокируется, пока сервер не вернул список инструментов. Это защищает от показа неподтверждённой интеграции как рабочей».

Не нажимать «Сохранить» для фиктивного endpoint. Для live-записи использовать только заранее поднятый тестовый MCP-сервер.

### 3:45–4:30 — Бизнес-ценность

«Инвестор видит не чат-бота общего назначения, а управляемый слой автоматизации: конкретная роль, проверяемые инструкции, собственные знания, навыки и контролируемые инструменты. Это сокращает время запуска новых процессов и позволяет безопасно тестировать агента до подключения к рабочим каналам».

Показать кнопку сохранения, тестовый результат и список навыков/инструментов.

### 4:30–5:00 — Завершение

«Следующий шаг — подключить подтверждённый источник данных и измерить точность, время ответа и экономию ручного труда на реальном процессе. В production включаются только те интеграции, у которых есть серверный executor и smoke-тест».

## Prompt для live-демонстрации

Скопируйте этот текст в тестовый чат агента после загрузки файла:

```text
Ты готовишь краткий управленческий отчёт по загруженному документу.

Задача:
1. Извлеки только проверяемые факты и укажи, из какого файла или раздела они взяты.
2. Составь таблицу: показатель, значение, период, изменение, источник.
3. Отдельно перечисли 3 наблюдения и 3 гипотезы. Гипотезы пометь явно и не выдавай их за факты.
4. Найди до 3 рисков. Для каждого укажи вероятность, влияние и ранний сигнал.
5. Сформируй план из 5 следующих действий с владельцем, сроком и критерием готовности.
6. Если данных не хватает, напиши «нет данных» и задай не более 3 уточняющих вопросов.

Формат ответа:
- Executive summary — максимум 5 предложений
- Таблица показателей
- Факты
- Гипотезы
- Риски
- Следующие действия
- Недостающие данные

Не придумывай числа, клиентов, источники или результаты. Отвечай на русском языке, коротко и по делу.
```

## Короткая версия для вертикального видео

«Создаём агента → выбираем навыки → загружаем собственную инструкцию в PDF или таблице → проверяем её в тестовом чате → подключаем HTTP или MCP-инструмент только после проверки endpoint. Nemo превращает инструкцию в повторяемый бизнес-процесс, а не просто генерирует текст».
