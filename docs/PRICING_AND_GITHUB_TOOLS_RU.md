# Тарифы Nemo AI и статус GitHub-инструментов

Актуальная продуктовая сетка после правки 22 июля 2026 года. В публичных тарифах каждый ресурс имеет конкретный предел или согласуется индивидуально.

## Что именно получает клиент

- AI-команды с менеджером, исполнителями и проверяющим агентом.
- Память и база знаний команды с изоляцией данных по аккаунтам.
- Выполнение задач в браузере в пределах тарифа с журналом действий.
- Генерация контента и медиа в пределах тарифа; Starter после пробного лимита использует ключ провайдера клиента.
- Премиум-модели, видео и повышенное качество доступны начиная с Pro согласно серверным ограничениям.
- Аналитика запусков, история результатов и контроль расхода токенов.
- Интеграции подключаются самим клиентом через OAuth или собственный API-ключ; секреты не показываются другим пользователям.

## GitHub-инструменты: решение по внедрению

| Инструмент | Назначение | Решение для Nemo |
|---|---|---|
| `garrytan/gstack` | процесс разработки, QA и релиз | уже установлен для Claude/Codex; не является функцией клиента |
| `shanraisshan/claude-code-best-practice` | рекомендации для Claude Code | использовать как справочник команды разработки |
| `Egonex-AI/Understand-Anything` | карта кода и документации | пилот для внутренней разработки, не включать в клиентский тариф без проверки |
| `alibaba/open-code-review` | автоматическое ревью кода | кандидат для будущего агента-разработчика после изолированного теста |
| `farion1231/cc-switch` | локальный менеджер AI CLI | не встраивать в веб-платформу; это инструмент рабочего компьютера разработчика |
| `elder-plinius/CL4R1T4S` | коллекция извлечённых системных промптов | не внедрять: риск безопасности, лицензирования и утечки инструкций |
| `JCodesMore/ai-website-cloner-template` | воспроизведение дизайна сайта | не давать как неограниченное клонирование; допустим только дизайн-анализ с проверкой прав |
| `StarTrail-org/PixelRAG` | визуальный RAG для страниц, PDF и изображений | перспективный пилот; нужен отдельный тест GPU, скорости, стоимости и RLS |
| `baidu/Unlimited-OCR` | OCR больших документов | перспективный пилот; сначала benchmark языков, памяти и времени обработки |
| `calesthio/OpenMontage` | агентный видеомонтаж | архитектурный пилот; перед интеграцией проверить AGPL, изоляцию и нагрузку |

Правило релиза: инструмент не показывается пользователю как работающий, пока нет исполнителя на сервере, проверки прав доступа, лимитов тарифа, журнала действий и живого smoke-теста.

## Перед следующим production-релизом

1. Выполнить живой checkout после подключения платёжного провайдера.
2. Проверить каждый тариф отдельным тестовым аккаунтом: UI и сервер должны выдавать одинаковые лимиты.
3. Проверить исчерпание токенов, медиа, видео и браузер-задач без скрытого превышения.
4. Запустить security live-тесты и мобильный smoke-тест.
5. Подключать GitHub-пилоты по одному, с возможностью отключения и без доступа к production-секретам.
