## 2. Карта пути (CJM)

Девять этапов. Для каждого: что происходит, что человек думает, где он отваливается, что должен сделать продукт, и по какой метрике мы это видим.

### Э1. Осознание проблемы

| | |
|---|---|
| **Триггер** | Потерянная заявка ночью. Клиент написал в 23:40, менеджер ответил в 9:20, клиент уже купил у другого |
| **Действия** | Считает потери в голове, спрашивает знакомых, гуглит «чат-бот для Инстаграм» |
| **Мысли** | «Нанять ещё одного менеджера — это 3,5–4 млн сум в месяц плюс налоги. И он тоже будет спать» |
| **Эмоция** | Раздражение, не любопытство. Это важно: он ищет не инновацию, а затычку |
| **Барьер** | Не знает, что существует что-то между «бот с кнопками» и «нанять человека» |
| **Что делает Nemo** | Контент и кейсы формулируются в деньгах и часах, не в фичах. Заголовок — не «мультиагентная платформа», а «отвечает ночью так же, как ваш лучший менеджер» |
| **Метрика** | Стоимость привлечения по каналу; доля трафика с запросов о найме, а не о ботах |

**Якорь замещения — главное число всей карты.** Менеджер по продажам в Ташкенте: **$297/мес** (кейс клиники, tipa.uz, май 2026) — **$340/мес** (вакансия, ish.uz, 2026), то есть 3,5–4 млн сум. Медиана вакансий hh.uz даёт $897 (февраль 2026), но это выборка объявлений, смещённая в сторону сеньорных ролей; для расчёта берём нижнюю границу **$297–340**.

Контекст: средняя зарплата по стране — $579, по Ташкенту — $992 (Q1 2026, Нацкомстат через kun.uz). Ташкентское среднее выше нашего якоря, и это не противоречие: $297–340 — ставка **линейного менеджера по продажам**, а $992 — среднее по всем ролям в столице, включая ИТ, финансы и руководителей. Для замещающего аргумента релевантна первая цифра, потому что заменяется именно эта роль.

Из этого следует потолок цены, и он — не $50.

### Э5. Первый результат — Shadow Mode

| | |
|---|---|
| **Действия** | Видит сплит-экран: слева ответ менеджера, справа ответ агента, по 20 реальным диалогам |
| **Мысли** | «Вот на этом клиенте мой менеджер написал ерунду, а тут нормально» |
| **Эмоция** | Первый момент доверия — и он основан на его собственных данных, а не на демо |
| **Барьер** | Если агент отвечает заметно хуже менеджера — доверие теряется навсегда, второй попытки не будет |
| **Что делает Nemo** | Ничего не отправляется наружу. Кнопки `[Агент лучше]` / `[Сотрудник лучше]` / `[В золотой набор]` |
| **Технический статус** | Инвариант shadow закреплён в БД (`runtime.outbox_actions`, `execution_mode='shadow'` ⇒ `status='simulated'`), но **диспетчер аутбокса не написан**, и чат-путь через аутбокс не проходит вовсе. См. `docs/reviews/001-outbox-dispatcher-review-brief.md` |
| **Метрика** | **Это и есть определение активации.** T1 = первый артефакт, помеченный владельцем как «отправил бы» |

Бенчмарк активации: медиана **37,0%**, среднее 37,5% (Userpilot, n=62, 2025); в сегменте AI & ML — **54,8%**. Выдающиеся PLG-компании по другой методике — 20–30% (OpenView, 2022 ⚠️ устарело). **Источники не усреднять**, у них разные определения активации.

Медианное time-to-value по рынку — **1 день 2 часа** (Userpilot, 2025). Shadow Mode нужен, чтобы уложиться в 15 минут; это и есть заявляемое преимущество.

| | |
|---|---|
| **Действия** | Включает агента на один канал, обычно на нерабочие часы |

### Э7. Регулярное использование

| | |
|---|---|
| **Действия** | Заходит раз в день посмотреть дайджест, иногда правит ответы |
| **Мысли** | «Работает. Сколько это мне стоит?» |
| **Барьер** | Тревога стоимости сильнее самой стоимости. Непонятный счёт останавливает масштабирование сильнее, чем высокая цена |
| **Что делает Nemo** | Pre-flight оценка диапазона до запуска, живой burn-down, юнит-экономика на артефакте: «это КП обошлось в $0,14, менеджер потратил бы 40 минут» |
| **Риск** | Approval fatigue: если подтверждений больше ~10 в день, владелец начинает штамповать «ОК» не глядя, и контроль становится фиктивным |
| **Метрика** | Недельная доля дней с заходом; доля автоодобренных действий |

### Э8. Расширение

| | |
|---|---|
| **Триггер** | Сработало на одном канале — подключает второй, потом второй бизнес-процесс |
| **Что делает Nemo** | Второй рецепт предлагается по данным, а не в общем списке: «у вас 40% вопросов про доставку — включить рецепт X» |
| **Бенчмарк** | Expansion в 2× дешевле нового логотипа: CAC ratio $0,80 против $1,63 (Benchmarkit 2026, n=342, CY-25) |
| **Ограничение** | Expansion при низком чеке почти не работает: при ARPA <$10/мес доля прироста ARR от expansion — **6,5%**, при >$500/мес — **39,2%** (ChartMogul, данные 2022 ⚠️ устарели). Ещё один аргумент против дешёвого тарифа |

### Э9. Отток

Причины в порядке ожидаемой частоты (🔵 гипотеза о порядке, не измерение):

1. Не дошёл до первого результата — отвалился на Э4/Э5.
2. Агент ошибся публично перед клиентом — потеря авторства, «мне не подошло».
3. Тихая деградация: качество поплыло, заметил через недели.
4. Сезонность бизнеса — приостановил, не вернулся.
5. Цена перестала оправдываться — не видит числа экономии.

Контрмеры 1–3 описаны в `ejm-2026-08.md` и в брифе для Codex; контрмера 5 — счётчик экономии на главном экране.

## 3. Модель LTV

### 3.1 Почему цена — самая важная переменная модели

Это самый консequential факт из всего исследования.

**ChartMogul + Kyle Poyar, «The SaaS Retention Report: The AI churn wave»** — данные по сентябрь 2025, 3 500 компаний, из них ~200 AI-native, только ≥$250k ARR, ставки годовые:

| Цена AI-продукта | GRR (год) | NRR (год) | Месячный отток (расчёт: 1 − GRR^(1/12)) |
|---|---|---|---|
| **<$50/мес** | **23%** | 32% | **~11,5%** |
| **$50–249/мес** | **45%** | 61% | ~6,4% |
| **>$250/мес** | **70%** | 85% | ~2,9% |
| Для сравнения: медиана B2B SaaS | не публикуется | 82% | — |

⚠️ Для строки B2B SaaS месячный отток **не считаем**: ChartMogul публикует по ней только NRR, а NRR включает расширение, поэтому `1 − NRR^(1/12)` — это темп изменения чистой выручки, а не отток, и он не сопоставим с тремя строками выше. Колонка заполняется только там, где известен GRR.

Разрыв в 3× по одной переменной. Медианная жизнь клиента AI-продукта дешевле $50/мес — **менее года**.

Оговорка самого автора: выборка ~50 на бакет, «directional, не statistically bulletproof». Но направление однозначно, и оно совпадает с ChartMogul по ARPA (данные 2022): logo retention при ARPA <$10/мес — 50,6%, при >$500/мес — 77,7%.

⚠️ **Противоречие, которое мы не примиряем:** отчёт ChartMogul SaaS LTV Report 2026 (n=3 331, данные Q1'20–Q4'24) даёт обратную картину — 12-месячная выживаемость 74% у самого дешёвого квартиля против 45% у самого дорогого. Оба факта фиксируем. Для AI-native когорты релевантнее первый датасет, потому что он именно про AI-продукты.

### 3.2 Вывод по позиционированию цены

Складываем два числа:

- потолок: менеджер стоит **$297–340/мес**;
- пол: ниже **$50/мес** продукт экономически не выживает (GRR 23%).

**Рабочий коридор основного тарифа: $100–290/мес за аккаунт**, и внутри него есть одна точка, которая важнее всех остальных. (Входной тариф может быть ниже — см. «Старт» $59 в `unit-economics-2026-08.md` §5.2, — но он служит воронкой в основной, а не самостоятельной ценовой позицией. Жёсткое ограничение только одно: не ниже $50.)

Отток меняется не плавно, а ступенями на границах бакетов. Значимых порогов два:

- **$50** — обрыв вниз. Ниже него GRR 23%, клиент живёт меньше года, экономика не сходится ни при каком CAC.
- **$250** — ступень вверх. Выше неё GRR 70% вместо 45%, отток падает более чем вдвое, LTV растёт вчетверо.

Одновременно потолок замещения — **$297–340** (зарплата менеджера). То есть между $250 и $297 существует узкое окно, где продукт уже находится в лучшем бакете удержания и всё ещё дешевле одного сотрудника. Это самая ценная точка на всей шкале, и она лежит выше, чем интуитивно хочется поставить цену.

MoonAI при 1 000 диалогов стоит эффективно **$63/мес** ($50 подписка + ~$13 токены) — то есть сидит в среднем бакете $50–249, у его нижней границы. Мы не обязаны туда идти следом.

Это не аргумент за дороговизну ради дороговизны. Это наблюдение, что при доказанной в Shadow Mode ценности разница между $63 и $260 не является для владельца решающей — он сравнивает не с MoonAI, а с $300 зарплаты, — а для нас это разница между жизнью клиента в 15 месяцев и в 34.

🔵 **Гипотеза, требующая проверки на реальных сделках:** готовность узбекского МСБ платить $100–150/мес за агента. Прямых данных о willingness to pay нет; косвенно — Bitrix24.uz продаёт 5 пользователей за 288 000 UZS (~$24,5), amoCRM Профессиональный — 249 000 UZS (~$21) за пользователя, то есть команда из 5 человек на amoCRM Pro = ~$105/мес. Это ближайший наблюдаемый ориентир расходов на софт.

### 3.3 Формула

Считаем корректно — с валовой маржой. Это не педантизм: правило «LTV/CAC > 3» David Skok (forentrepreneurs.com, обновлено 18.06.2026) сопровождается прямой оговоркой, что оно **действует только при GM ≥80% и LTV, посчитанном по выручке**. При марже AI-продукта применение 3× к выручке завышает допустимый CAC примерно в 1,45 раза.

```
LTV = ARPA × Gross Margin % / monthly churn
```

a16z требует ещё строже — contribution margin вместо gross margin. Разницу фиксируем, в расчёте ниже используем gross margin по Skok и помечаем это.

### 3.4 Три сценария

Валовая маржа — из `unit-economics-2026-08.md` §2.3–2.4 (рабочий потолок планирования 75–82%). Отток берётся **строго по бакетам ChartMogul, без интерполяции**: бакеты дискретны, выборка внутри каждого ~50 компаний, поэтому промежуточных значений вида «при $200 отток 4%» не существует и придумывать их нельзя.

Соответственно сценарии различаются не подгонкой оттока, а тем, **в какой бакет попадает цена**.

| | Пессимистичный | **Базовый** | Оптимистичный |
|---|---|---|---|
| ARPA/мес | $45 | **$140** | $260 |
| Бакет удержания | **<$50** | $50–249 | **>$250** |
| Месячный отток | **11,5%** | **6,4%** | **2,9%** |
| Валовая маржа (текст, без голоса) | 76% | **82%** | 82% |
| **LTV** | **$297** | **$1 794** | **$7 352** |
| Средняя жизнь, мес. | 8,7 | 15,6 | 34,5 |
| LTV/CAC при CAC $600 | **0,50×** | 2,99× | **12,25×** |

🔵 ARPA и маржа — допущения. Из данных взят только отток по бакету.

**Главное, что показывает таблица: разница между сценариями создаётся почти целиком ценой, а не операционным качеством.** Между пессимистичным и оптимистичным — 25× по LTV, и ARPA отличается менее чем в 6 раз. Остальное делает бакет удержания.

**Что ломает модель:** цена ниже $50. При ARPA $45 LTV = $297; даже при самом дешёвом бенчмарке CAC для SMB ($274, eCommerce SaaS, First Page Sage 29.08.2025) отношение LTV/CAC = 1,08×, при более реалистичном CAC $600 — 0,50×. Каждый привлечённый клиент приносит убыток. Бизнеса нет ни при каком объёме.

### 3.5 Что сделает модель доказанной

Три измерения, которых у нас сейчас нет и которые нельзя вывести из кода:

1. **Реальная конверсия Э5 → Э6** (активация → live) на первых 30 аккаунтах.
2. **Фактический ARPA** после первых платящих — не прайс-лист, а то, что реально списалось.
3. **Отток за 3 и 6 месяцев** первой когорты. До этого любой LTV — арифметика над предположениями.

До получения этих трёх чисел документ является планом измерения, а не результатом.

Требование верное.
