## Шаг 1 — Создание агента (типы + детальные настройки)

### 1.1 Новые типы агентов (`AgentKind`)
Текущие: `chat`, `qualifier`, `research`, `workflow`. Добавляем:

| kind | Что делает | Поведение редактора | Бэкенд |
|------|------------|---------------------|--------|
| `manager` (Отдел/Менеджер) | Главный агент собирает команду под-агентов под сферу и управляет | вкладка Run (как workflow) + (Phase B) вкладка «Отдел» | `orchestrate` (расширить: динамические роли) |
| `coder` (Кодер) | Пишет/правит код, работает с файлами/репо | вкладка Run | новый путь поверх `orchestrate`/`research-agent` |
| `content` (Контент) | Тексты, посты, описания, креатив | вкладка Run или чат | reuse chat/run |
| `learning` (Самообучающийся) | Чат с памятью — улучшается с каждым диалогом | как chat + индикатор памяти | chat-путь + таблица памяти |

Для каждого: иконка + цвет (`platformMeta`), i18n (uz/ru/en), дефолтная модель, скелет промпта,
набор вкладок в редакторе.

### 1.2 Детальные настройки агента (новые поля, необязательные)
- `language` — уже есть.
- `country` — страна (для контекста/региональных норм).
- `purpose` — «для чего используется» (короткое назначение).
- `niche` — ниша/сфера (напр. образование, e-commerce, недвижимость…). Влияет на промпт и на роли в отделе.

**Данные:** `agents` + колонки `country text`, `purpose text`, `niche text` (nullable).
**Типы:** `PlatformAgent` += `country?/purpose?/niche?`.
**UI:** новый блок в онбординге (шаг 1) и в редакторе (вкладка General), сворачиваемый «Доп. настройки».

## Шаг 4 — Цены (зафиксировано, всё в USD)

Источник правды по числам: `src/data/billing.ts` (+ дублируется в `create-checkout`).

### Себестоимость одного агента (в месяц)
Архитектура serverless (Supabase + Edge Functions), агент = строки в БД + вызовы функций.
- Supabase Pro: $25/мес на весь проект → при ~300 агентах ≈ **$0.08/агент**.
- VPS (под будущие always-on воркеры / обещание «агент на нашем сервере»): ~$12/мес,
  делится на всех → при 300 агентах ≈ **$0.04/агент**.
- Поддержка/буфер: ~$0.10/агент.
- **Итого себестоимость ≈ $0.20–0.30 / агент / месяц.** (LLM-токены НЕ входят — они метятся отдельно.)

### Решение по цене
- **Цена агента: $4 / агент / месяц** (`AGENT_PRICE_USD`). Покрывает хостинг на VPS + доступ к нашему API.
  Маржа ~13–20× к себестоимости — заложен запас на поддержку и скидки. **Не меняем.**
  (Сейчас показывается как информация при создании; списание per-agent — в Шаге 4b.)
- **Токены (метятся отдельно):** базовый курс **$1 = 50 000 токенов** (`USD_TO_TOKENS`).
  Пакеты дают больше за $ (скидка за объём): $5→250k (50k/$), $20→1.2M (60k/$), $50→3.5M (70k/$).
  В цену токена уже заложена «доп плата за наш API-токен» (наценка над OpenRouter).
- **Кастомное пополнение:** любая сумma $1–$500, токены считаются на сервере (`usd × 50 000`),
  клиент не задаёт количество токенов (защита от подмены). Кнопка оплаты — снизу.
- **Калькулятор:** ~3 000 токенов/диалог (`TOKENS_PER_DIALOGUE`) → оценка в $/мес.

### Что дальше по Шагу 4 (по ТЗ — пришлёт клиент)

- Мульти-агент общается с юзерами через Telegram и др. каналы.

- Бесплатные модели OpenRouter не умеют веб-поиск (Sonar платный) и иногда лимитируются (есть retry).
- Все ключи — только на сервере (edge functions). Фронт никогда не видит секреты.
- Секреты, засвеченные в чате ранее, нужно ротировать.
